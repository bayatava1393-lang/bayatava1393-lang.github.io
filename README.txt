AVA BAYAT — BILINGUAL WEBSITE

فارسی:
فایل index.html را باز کنید.

English:
Open en/index.html.

مهم:
کل پوشه را با همین ساختار آپلود کنید.
پوشه en نباید جداگانه آپلود شود؛ چون دکمه‌های فارسی و انگلیسی با مسیر نسبی به هم وصل شده‌اند.

ساختار:
index.html          ← Persian home
settings.html       ← Persian settings
en/index.html       ← English home
en/settings.html    ← English settings

Language switching is now connected in both directions.
